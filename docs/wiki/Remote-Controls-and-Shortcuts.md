# 🎮 Remote Controls & Navigation Shortcuts

Zen TV is designed from the ground up for 100% remote-first interaction without requiring a mouse or touch input.

---

## 🕹️ Key Bindings Reference

| Remote Button | Action in Zen TV |
| :--- | :--- |
| **D-Pad Directionals** (Up / Down / Left / Right) | Navigate through Favorites, Apps Grid, and Top Bar items with smooth focus glow. |
| **D-Pad Center / OK / ENTER** | Launch the focused application, or confirm dialog actions. |
| **Long-Press D-Pad Center** | Open the **App Context Menu** (Add/Remove Favorite, Reorder, Hide, App Info, Uninstall). |
| **MENU / SETTINGS Key** | Instantly opens the launcher's glassmorphic **Settings Overlay** from anywhere. |
| **TV / INPUT Key** | Opens the **Hardware Input Switcher** (HDMI 1 ARC, HDMI 2, AV, Live TV). |
| **BACK Key** | Dismisses active menus / settings / overlays, or returns focus to the TopBar / Home. |

---

## 💡 Pro-Tips for Low-Memory TVs

- **One-Tap RAM Cleaner**: Click the broom/cleaner icon in the TopBar or Settings to clear cached background processes before launching heavy apps like Netflix or Kodi.
- **Hide System Bloat**: Long-press on pre-installed factory apps that you don't use and select **Hide App** to keep your grid tidy and fast.
